# Diagrams

Three views of the system, in increasing detail. Read the **overview** first to get the shape, the **detailed** one when you need to know which module talks to which, and the **user flow** to see the product from the user's side.

> These are [Mermaid](https://mermaid.js.org/) diagrams. They render as flowcharts in the Nuxt Content site; in a plain Markdown viewer you'll see the code. Before editing them, read the [diagram documentation guide](/guides/diagrams).

## 1. Overview - how the pieces fit

The three processes never call each other directly. The **database is the only channel**: the browser and worker both talk to Postgres, and coordinate through the `jobs` table.

```mermaid
flowchart TD
    User(["User's browser"])

    subgraph Frontend["Frontend - app/ (Vue, runs in browser)<br/><br/>"]
        Pages["Pages + Components"]
        State["Pinia stores + composables"]
    end

    subgraph NuxtServer["Nuxt server - server/api/ (Nitro)<br/><br/>"]
        API["HTTP API routes<br/>auth + ownership + DB access"]
    end

    subgraph Worker["Worker - server/worker/ (background process)<br/><br/>"]
        Loop["Poll loop (every 3s)"]
        Handlers["Job handlers"]
        Providers["Provider adapters"]
    end

    subgraph Supabase["Supabase (managed)<br/><br/>"]
        DB[("Postgres<br/>jobs, scenes, outputs, …")]
        Storage[("Storage bucket 'assets'<br/>images, audio, video")]
        Auth["Auth (email/password)"]
    end

    ExtAI["External AI APIs<br/>Claude, fal, ElevenLabs, Runway, …"]

    User --> Pages
    Pages --> State
    State -->|"$fetch /api/*"| API
    User -->|"login/signup"| Auth

    API -->|"user-scoped client (RLS)"| DB
    API -->|"upload/serve files"| Storage

    Loop -->|"claim queued job (admin client)"| DB
    Loop --> Handlers
    Handlers --> Providers
    Providers -->|"generate"| ExtAI
    Handlers -->|"write outputs"| DB
    Handlers -->|"store media"| Storage

    State -.->|"poll job status every 2s"| API
```

**The core loop:** a component submits a job (`POST /api/jobs` → row inserted `queued`), then polls `GET /api/jobs/:id` every 2 s. Meanwhile the worker claims the job, runs a handler, calls an AI provider, writes results to `job_outputs` + Storage, and marks it `completed`. The next poll sees the result and the UI updates reactively.

See [architecture.md](/overview/architecture) for the narrative version.

## 3. User flow - the product from the outside

What a person actually does, and the pipeline stage each step advances (`projects.current_stage`). Tabs unlock left-to-right; regeneration and going back are always allowed.

```mermaid
flowchart TD
    Start(["Visit site"]) --> Auth{"Signed in?"}
    Auth -->|No| Signup["Sign up / Log in<br/>(Supabase email auth)"]
    Signup --> Dash
    Auth -->|Yes| Dash["Dashboard - project list"]

    Dash --> New["Create project"]
    New --> WS["Open workspace"]
    Dash -->|"open existing"| WS

    WS --> Key{"Provider API<br/>key saved?"}
    Key -->|No| PasteKey["Paste key in model selector<br/>(stored encrypted)"]
    PasteKey --> ScriptTab
    Key -->|Yes| ScriptTab

    subgraph Pipeline["Editing pipeline (tabs)<br/><br/>"]
        direction TB
        ScriptTab["SCRIPT tab<br/>enter idea + tone + length"] --> Gen3["Generate 3 script options"]
        Gen3 --> Pick["Pick one · edit · refine"]
        Pick --> Split["Split into scenes<br/>→ stage: scene_split"]
        Split --> EditScenes["Tweak scene text / order / add / delete"]

        EditScenes --> ImgTab["IMAGE tab<br/>→ stage: image"]
        ImgTab --> ImgPrompts["Generate image prompts"]
        ImgPrompts --> ImgGen["Generate / upload image per scene"]

        ImgGen --> AudTab["AUDIO tab<br/>→ stage: audio"]
        AudTab --> Voice["Choose voice + settings"]
        Voice --> AudGen["Generate voiceover per scene<br/>→ combine into one track"]

        AudGen --> VidTab["VIDEO tab<br/>→ stage: video"]

    Slideshow --> ExportStage

    ExportStage --> Export["Export MP4<br/>(ffmpeg assembles everything)"]
    Export --> Download(["Download video + manifest"])
```
