# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting or contact the repository owner
through [GameDevRaf on GitHub](https://github.com/GameDevRaf). Include the
affected path, reproduction steps, impact, and any suggested mitigation.

## Scope

The `master` branch is the supported development branch. This project is a
portfolio application and does not promise a security response time or
security support for deployed forks.
